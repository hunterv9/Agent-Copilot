# GLOSSARY

- `Team Lead`: agent điều phối. Không dùng `Team_Lead`.
- `Free_Model`: ID cũ, đã thay bằng `claude-fable-5-1` / `claude-opus-5`.
- `QC`: quality gate, verdict `APPROVED` / `CONDITIONAL` / `REJECTED`.
- `Evidence`: diff, test log, security report, build log.
- `Fail closed`: thiếu evidence = dừng, không đoán.
